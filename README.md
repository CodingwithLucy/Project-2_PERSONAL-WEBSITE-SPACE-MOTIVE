# Personal Portfolio & Consulting Website

A modern, responsive two-page website built to present a professional profile and a dedicated consulting offer with clarity, elegance, and high performance.
The project focuses on clean structure, smooth user experience, and visually cohesive design across both pages.

## ✨ Key Features:

- **Fully Responsive Design:** Seamless experience across mobile, tablet, and desktop devices.
- **Modern Navigation:** Fixed top navigation with smooth hover effects, soft glow styling, and intuitive section-based scrolling.
- **Single Page Architecture:** Intuitive section-based navigation with smooth scrolling.
- **Performance Optimized:** Significant asset optimization, reducing total size for lightning-fast loading speeds.
- **Resource Section:** Dedicated articles section with external link integration.
- **Refined Visual Design:** Galaxy‑inspired aesthetic with subtle blurs, soft gradients, and polished micro‑interactions.
- **Optimized Assets:** Images and graphical elements compressed and cleaned for fast loading and improved performance.
- **Clean Code Architecture:** Organized HTML structure and modular CSS with Grid/Flexbox for maintainability and scalability.

## 🛠️ Tech Stack:

- **HTML5:** Semantic markup for better SEO and accessibility.
- **CSS3:** Modern layouts using Flexbox/Grid with a focus on visual precision.
- **Media Optimization:** compressed images, reduced asset weight, and performance‑oriented styling.

## 📁 Project Structure:

🟣 Main Page (Portfolio / CV)

- **Header:** Fixed navigation bar with soft hover effects and smooth transitions.
- **Hero Section:** Name, professional title, and a personal quote.
- **About Me:** Profile description with responsive image layout and clean typography.
- **Skills:** Grid‑based skill cards with icons and structured content.
- **Education & Experience:** A clear chronological timeline of professional growth.
- **Articles:** Curated list of publications with active external links.
- **Contact:** Footer section designed for easy communication.

🔵 Offer Page (Consulting / Services)

- **Hero banner:** Dedicated header with background image and page title.
- **Expertise:** Overview of scientific and technical areas of specialization.
- **Services:** Structured service cards describing available consulting options.
- **Process:** Timeline-style workflow explaining how collaboration works.
- **Philosophy:** Three pillars of scientific approach + inspirational quote.
- **Pricing:** Clean, modern pricing list for individuals and companies.
- **Testimonials:** Speech-bubble style client feedback with subtle glow effects.
- **Footer:** Shared navigation and contact links consistent with the main page.

## 📝 About the Project:

This project was created as a modern, scalable personal website combining a professional CV with a dedicated consulting offer.

The main challenge involved refining layout consistency across two separate pages, improving responsiveness, and designing custom UI components such as timelines, pricing lists, and testimonial bubbles — all while maintaining a cohesive galaxy-inspired visual identity.

The project is designed to be fully extensible — ready for additional sections, new service categories, or future portfolio expansions.
